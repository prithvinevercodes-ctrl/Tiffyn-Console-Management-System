# 📖 About The Project

Managing meal subscriptions manually can be inconvenient for both customers and vendors. Tracking meal plans, subscriptions, customer records, and orders often becomes time-consuming and error-prone.

**Tiffyn** is a console-based Java application designed to solve this problem by providing a simple and organized meal subscription management system.

This project is also part of my journey to apply Core Java concepts to a real-world problem while following professional software development practices.
